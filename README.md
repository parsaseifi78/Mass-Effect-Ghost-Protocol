## The story continues

Randall Ezno returns from Sur’Kesh. The Alliance has traced Cerberus’s rebuilt Inali program to a desert redoubt, where the Director is preparing a controllable biotic soldier. Ghost Protocol is a fan-written continuation built as an original three.js game for modern Android phones — playable offline, with no EA services and no external assets.

The original Resurrection project remains available at [Mass Effect Infiltrator: Resurrection](https://github.com/parsaseifi78/Mass-effect-infiltrater-Resurrection).

---

## What is in the sequel

- A custom **three.js r160** renderer tuned for phones: capped DPR, no shadows, adaptive render scale, and native `Choreographer` frame pacing with rAF fallback.
- Swipe-only **biotic wheel** with three visible slots; the biotic button itself never casts. The bottom-right button is permanently mapped to Cloak.
- **150 health**, health regeneration before shields, and vitals bars that desaturate toward neutral steel instead of darkening.
- A compact HUD: minimap, morality, objective panel, and vitals tile into one map-height stack with no health or shield numbers.
- Cinematic Praetorian, Lancer, Juggernaut, and Director encounters, hand-written dialogue, and two sequel endings.
- Full **English / Persian** UI and controller rebinding.
- Local multiplayer: 2-player co-op and PVP with FFA or Team A vs B. One limited-use ability and one weapon before each round.

## Install

1. Copy the APK from `/sdcard/Download/Ghost Protocol/` to the device.
2. Open it and install. The package is `com.ghost.protocol`, so it can sit beside the Resurrection build.
3. Launch **Ghost Protocol**. No account, network connection, or EA Online dependency is required.

Current build line: **v7.13.47**, `versionCode 153`.

## Controls

| Action | Touch / mouse | Keyboard | Gamepad |
| --- | --- | --- | --- |
| Move / aim | Bottom-centre fire pad | WASD + pointer | Left + right sticks |
| Fire | Fire pad | Mouse click | RT |
| Biotics | Drag top-left circle onto a slot and release | `E` / `1`–`3` | Face buttons |
| Weapon wheel | Top-right weapon panel | `Q` | D-pad |
| Cloak | Bottom-right button, always | `C` | Shoulder button |
| Melee | Compact right-side button | `F` | Face button |
| GitHub picker | Top-left circle/triangle on the title screen | `G` | Menu Back / interact |
| Exit | Bottom-right `×` on the title screen | `Esc` | Menu Back |

## Build from source

```sh
bash tools/build_apk.sh "/sdcard/Download/Ghost Protocol/GhostProtocolLocal.apk"
```

Run the headless checks:

```sh
node --check game3d/game.js
node --check game3d/test.js
(cd game3d && node test.js)
```

The Android shell is assembled from `apk_app/smali`, packages `apk_app/assets`, and signs with the project key. The shipped `apk_app/assets/game.js` is copied from `game3d/game.js` before each release build. The signing keystore is intentionally not included; place your own `keys/game2d.jks` locally before building.
